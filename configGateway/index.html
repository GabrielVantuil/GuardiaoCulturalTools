Monitor Serial

Comunicação em tempo real com o ESP32

Referência do Protocolo JSON (USB Serial ↔ ESP32)

1. Salvar apenas Wi-Fi (set_config parcial)

Altera somente wifi_ssid e wifi_password na NVS e reconecta o Wi-Fi, mantendo os parâmetros do Beacon intactos.

{"cmd":"set_config","wifi_ssid":"MinhaRede","wifi_password":"MinhaSenha"}\n

2. Salvar apenas Beacon & API (set_config parcial)

Atualiza beaconApikey, beaconId e urlbase sem derrubar ou reconectar o Wi-Fi atual.

{"cmd":"set_config","beaconApikey":"SUA_API_KEY","beaconId":"3fa85f64-5717-4562-b3fc-2c963f66afa6","urlbase":"https://www.guardiaocultural.com.br"}\n

3. Salvar Tudo (set_config completo)

Envia todas as credenciais e parâmetros em uma única linha JSON terminada com \n.

{"cmd":"set_config","wifi_ssid":"MinhaRede","wifi_password":"MinhaSenha","beaconApikey":"SUA_API_KEY","beaconId":"3fa85f64-5717-4562-b3fc-2c963f66afa6","urlbase":"https://www.guardiaocultural.com.br"}\n

4. Ler Configuração (get_config)

Solicita os valores atuais salvos na NVS. Ao receber o JSON de resposta, a interface preenche os campos automaticamente.

{"cmd":"get_config"}\n

5. Reiniciar Gateway (reboot)

Reinicia o ESP32 imediatamente via ESP.restart() após confirmar o recebimento pela serial.

{"cmd":"reboot"}\n
